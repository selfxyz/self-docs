# Document specifications

Technical specifications for the credential types Self Enterprise verifies. These pages explain the cryptographic and protocol-level shape of each document, useful when integrating, auditing, or debugging document-specific behavior.

* [Aadhaar](aadhaar.md): India's national ID, with ZK-friendly signature verification.
* [KYC](kyc.md): partner-issued KYC attestations.

For an overview of which documents support which disclosures, see [Supported documents](../../flows/supported-documents.md). For country coverage, see [Supported countries](../supported-countries.md).
